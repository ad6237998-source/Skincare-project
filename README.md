# SkinCare 🌿

A responsive skincare guidance website built using HTML, CSS, and JavaScript.

## About the Project

SkinCare is a beginner-friendly frontend project that helps users explore basic skincare guidance based on their selected skin type, main skin concern, and budget preference.

The website focuses on a simple interface, responsive design, and interactive form functionality.

## Features

- Clean and aesthetic user interface
- Responsive layout for desktop and mobile
- Skin type selection
- Skin concern selection
- Budget preference selection
- Personalized basic skincare suggestions
- Morning and evening routine guidance
- Product essentials section
- Dynamic copyright year
- Interactive navigation

## How to Run

1. Clone or download this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` in your browser.
4. Alternatively, use the Live Server extension in VS Code.

## How It Works

1. Select your skin type.
2. Select your main skin concern.
3. Choose your preferred budget.
4. Click "Discover My Routine".
5. View the suggested skincare guidance.

## Limitations

This is a frontend-only educational project.

- No database is connected.
- User profiles are not saved.
- Product suggestions are rule-based examples.
- The application does not diagnose skin conditions.
- The project does not currently have a backend or authentication system.
